Topic 1 — Linear Equations
1.1 Row operations · 1.2 Row-echelon form · 1.3 Reduced REF · 1.4 Consistent & inconsistent systems

What is a linear equation?

An equation where every variable appears to the power 1, with no products between variables. The general form is a₁x₁ + a₂x₂ + ··· + aₙxₙ = b. A system is a collection of these equations solved simultaneously.

The 3 row operations (never change the solution set)

R1 — Swap two rows: Rᵢ ↔ Rⱼ R2 — Scale a row by c ≠ 0: Rᵢ → c·Rᵢ R3 — Add multiple of one row: Rᵢ → Rᵢ + c·Rⱼ

Always write row operations explicitly in the exam — you lose marks for skipping notation.

Augmented matrix

Write the system as [A|b] — coefficient matrix A with constants b as an extra column. All row operations are performed on this combined matrix.

Trap: 3x − xy = 1 is NOT linear (product xy). Non-linear systems cannot be solved by these methods.

Row-Echelon Form (REF)

A matrix is in REF when all-zero rows are at the bottom, and in each non-zero row the leading entry is strictly further right than the row above.

REF pattern (★ = leading entry, * = anything): [ ★ * * * ] [ 0 ★ * * ] [ 0 0 ★ * ] [ 0 0 0 0 ]

Gaussian Elimination

1. Bring non-zero entry to top-left (swap if needed) 2. Zero out everything BELOW the pivot with R3 ops 3. Ignore that row/column, repeat on the smaller submatrix 4. Read off solution by back-substitution from bottom up
Free variables = columns WITHOUT a pivot. If there are k free variables, you get k parameters in the general solution.

Reduced Row-Echelon Form (RREF)

REF plus two extra conditions: each leading entry is exactly 1, and all entries above a leading 1 are also zero.

RREF pattern: [ 1 0 * * ] [ 0 1 * * ] [ 0 0 0 0 ]

RREF is unique — there is only one RREF for any matrix. REF is not unique.

Gauss-Jordan Elimination

1. Do Gaussian elimination → REF 2. Divide each non-zero row to make leading entries = 1 3. Zero out entries ABOVE each leading 1 too 4. Read off answers directly (no back-substitution needed)
Exam tip: RREF gives answers directly. For questions about existence/uniqueness, REF is usually faster.

Consistent vs Inconsistent

After row reduction, look for a row of the form [0 0 0 … 0 | c] with c ≠ 0. This says 0 = c — impossible. System is inconsistent (no solution). Otherwise it is consistent.

Counting solutions

r = rank = number of pivot columns n = number of unknowns No free variables (r = n): unique solution Free variables present (r < n): infinitely many solutions Inconsistent row exists: no solution

Parametric solutions

When free variables exist (say x₃=t, x₄=s), express pivot variables in terms of t and s. Write as: x = x_particular + t·v₁ + s·v₂.

For systems with a parameter k: row reduce symbolically, then ask — what value of k makes the last row become [0 0 … | c] with c ≠ 0?
Example. The augmented matrix [[1,2,3a|−1],[0,1,−1|4b],[0,0,a−3|b+2]] — find values of a,b for (i) no solution, (ii) unique solution, (iii) infinitely many solutions.
1Matrix is already in REF. The deciding row is row 3: [0, 0, a−3 | b+2].
iNo solution: coefficient = 0 but RHS ≠ 0 → a−3=0 and b+2≠0 → a=3, b≠−2.
iiUnique solution: a−3≠0 (full rank, pivot in every column) → a≠3, b arbitrary.
iiiInfinitely many: entire last row = 0 → a=3 AND b=−2 → a=3, b=−2.

Topic 2 — Matrices & Determinants
2.1 Notation · 2.2 Operations · 2.3 Inverses · 2.4 Elementary matrices · 2.5 Systems · 2.6 Determinants

Matrix multiplication

(AB)ᵢⱼ = row i of A dotted with column j of B. Only defined when #cols(A) = #rows(B). NOT commutative: AB ≠ BA in general.

(AB)ᵀ = BᵀAᵀ ← order reverses on transpose (AB)⁻¹ = B⁻¹A⁻¹ ← order reverses on inverse A(B+C) = AB + AC ← distributive

Matrix inverse

A is invertible iff AA⁻¹ = I. Find A⁻¹ by row reducing [A|I] → [I|A⁻¹].

For 2×2: if A = [[a,b],[c,d]], then A⁻¹ = (1/(ad−bc)) · [[d,−b],[−c,a]] Only when det(A) = ad−bc ≠ 0.
Most common mistake: (AB)⁻¹ = A⁻¹B⁻¹ is WRONG. It must be B⁻¹A⁻¹ — order reverses.

Determinant key facts

det([[a,b],[c,d]]) = ad − bc det(AB) = det(A)·det(B) det(Aᵀ) = det(A) det(A⁻¹) = 1/det(A) det(kA) = kⁿ·det(A) (n×n matrix) Row ops effect on det: Swap rows → det changes sign Scale row → det scales by same factor Add multiple → det unchanged
A matrix is invertible ⟺ det ≠ 0. For triangular matrices, det = product of diagonal entries.
Example. If det(A)=3 and A is 3×3, find det(2A), det(A⁻¹), det(Aᵀ), det(A²).
1det(2A) = 2³·det(A) = 8×3 = 24
2det(A⁻¹) = 1/det(A) = 1/3
3det(Aᵀ) = det(A) = 3
4det(A²) = det(A)² = 9
Warm-Up
A is invertible and AB=AC. Prove B=C.
Left-multiply both sides by A⁻¹: A⁻¹(AB)=A⁻¹(AC) → (A⁻¹A)B=(A⁻¹A)C → IB=IC → B=C. ∎

Topic 3 — Euclidean Vector Spaces
3.1 Vectors in ℝⁿ · 3.2 Dot product · 3.3 Cross product · 3.4 Lines and planes

Dot product and geometry

u·v = u₁v₁+u₂v₂+···+uₙvₙ = ‖u‖‖v‖cos θ ‖u‖ = √(u·u) u ⊥ v ⟺ u·v = 0 cos θ = u·v / (‖u‖‖v‖)

Projection formulas

Vector projection of u onto v: proj_v u = (u·v / ‖v‖²) · v Scalar projection (length of shadow): comp_v u = u·v / ‖v‖ Component of u perpendicular to v: u − proj_v u

Cross product (ℝ³ only)

u×v = det([[i,j,k],[u₁,u₂,u₃],[v₁,v₂,v₃]]) = (u₂v₃−u₃v₂, u₃v₁−u₁v₃, u₁v₂−u₂v₁) • u×v is perpendicular to BOTH u and v • ‖u×v‖ = area of parallelogram spanned by u,v • u×v = −(v×u) (anti-commutative) • u×u = 0
Cross product only exists in ℝ³. Dot product works in any ℝⁿ.

Lines and planes

Line through p with direction d: x = p + t·d, t∈ℝ Plane with normal n=(a,b,c) through point p: a(x−p₁) + b(y−p₂) + c(z−p₃) = 0 i.e. ax + by + cz = d Distance from point q to plane ax+by+cz=d: dist = |aq₁+bq₂+cq₃−d| / √(a²+b²+c²)
Normal vector to plane ax+by+cz=d is (a,b,c). To find normal to a plane through 3 points: get two vectors in the plane, then take their cross product.
Example. Find the plane through P=(1,0,2), Q=(2,1,0), R=(0,3,1). Then find the distance from S=(4,0,0) to this plane.
1Vectors in the plane: PQ=(1,1,−2), PR=(−1,3,−1).
2Normal n=PQ×PR=(1(−1)−(−2)(3), (−2)(−1)−(1)(−1), (1)(3)−(1)(−1))=(5,3,4).
3Plane: 5(x−1)+3y+4(z−2)=0 → 5x+3y+4z=13.
4Distance from S=(4,0,0): |20+0+0−13|/√50 = 7/5√2 = 7√2/10.

Topic 4 — General Vector Spaces
4.1 Vector spaces · 4.2 Subspaces · 4.3 Span · 4.4 Linear independence · 4.5 Bases · 4.6 Row/Col/Null spaces · 4.7 Coordinates

3-test for subspaces

W is a subspace of V iff it passes all three:

1. Zero vector: 0 ∈ W 2. Closed under addition: u,v∈W → u+v∈W 3. Closed under scaling: u∈W, c∈ℝ → cu∈W Combined shortcut: u,v∈W → au+bv∈W for all a,b∈ℝ

To disprove: find ONE counterexample to ONE test. Check test 1 (zero vector) first — it's the fastest.

Span and linear independence

To test if b ∈ span{v₁,...,vₖ}: row reduce [v₁|...|vₖ|b] and check consistency.

Vectors are linearly independent iff the only solution to c₁v₁+...+cₖvₖ=0 is all cᵢ=0. Test: row reduce the matrix with vectors as columns — independent iff every column has a pivot.

k vectors in an n-dim space with k > n are ALWAYS linearly dependent.

Basis and dimension

A basis is a set that is both (1) linearly independent AND (2) spans V. The dimension is the size of any basis.

dim(ℝⁿ)=n, dim(Pₙ)=n+1, dim(Mₘₙ)=mn Rank-Nullity Theorem: rank(A) + nullity(A) = n (n = #columns)

The three fundamental spaces

Row space: span of rows of A basis = non-zero rows of REF of A Column space: span of columns of A basis = PIVOT columns of ORIGINAL A Null space: solution set of Ax=0 basis = free variable vectors from RREF
Critical: for column space, take pivot columns from the ORIGINAL matrix, not from RREF. Row operations change column values.
Example. Find bases for the row space, column space, and null space of A=[[1,2,3],[2,4,6],[1,2,4]].
1Row reduce: get REF [[1,2,3],[0,0,1],[0,0,0]]. Pivots in columns 1 and 3.
2Row space basis: {(1,2,3),(0,0,1)}. Dim=2=rank.
3Column space basis: pivot cols 1&3 from ORIGINAL A: {(1,2,1)ᵀ,(3,6,4)ᵀ}.
4Null space: Free var x₂=t. x₃=0, x₁=−2t. Basis: {(−2,1,0)ᵀ}. Nullity=1. Check: 2+1=3=n ✓
Warm-Up
Is W = {(x,y,z)∈ℝ³ : x+y+z=1} a subspace of ℝ³?
No. Test 1 fails: (0,0,0) gives 0+0+0=0≠1, so 0∉W. A subspace must contain the zero vector. ∎

Topic 5 — Linear Transformations
5.1 Definition · 5.2 Geometric transforms · 5.3 Matrix representations · 5.4 Image & kernel · 5.5 Invertible · 5.6 Change of basis

What makes T linear?

T(u+v) = T(u) + T(v) (additivity) T(cu) = cT(u) (homogeneity) Combined: T(cu+dv) = cT(u) + dT(v)

To prove T is linear: verify these for arbitrary vectors u,v and scalars c,d. To disprove: find ONE counterexample. Quick check: T(0)=0 must hold — if T(0)≠0 then T is not linear.

Finding the matrix representation

Standard matrix of T:ℝⁿ→ℝᵐ: [T] = [ T(e₁) | T(e₂) | ··· | T(eₙ) ] columns = images of standard basis vectors Matrix of T:V→W w.r.t. bases B and C: [T]_{C←B} has columns = [T(bᵢ)]_C

Geometric transforms in ℝ²

Rotation by θ: [[cosθ,−sinθ],[sinθ,cosθ]] Reflection in y=x: [[0,1],[1,0]] Reflection x-axis: [[1,0],[0,−1]] Projection x-axis: [[1,0],[0,0]] Horizontal shear: [[1,k],[0,1]]

Kernel and Image

ker(T) = {v : T(v)=0} = null space of [T] im(T) = {T(v)} = column space of [T] Injective (one-to-one): ker(T)={0}, i.e. nullity=0 Surjective (onto): im(T)=W, i.e. rank=dim(W) Rank-Nullity: rank(T) + nullity(T) = dim(domain)

Change of basis

P_{S←B} = [b₁|b₂|···|bₙ] (cols = basis vectors) P_{B←S} = (P_{S←B})⁻¹ Matrix of T in new bases: [T]_{new} = P⁻¹ · [T]_{std} · P
Change of basis = convert to standard → apply T → convert back. The formula P⁻¹[T]P follows this exactly.
Example. T:P₂→P₂ defined by T(p(x))=p(2x+1). Find [T]_B where B={1,x,x²}.
1T(1)=1, T(x)=2x+1, T(x²)=(2x+1)²=4x²+4x+1.
2Express in basis B: [T(1)]_B=(1,0,0), [T(x)]_B=(1,2,0), [T(x²)]_B=(1,4,4).
3[T]_B = [[1,1,1],[0,2,4],[0,0,4]].

Topic 6 — Eigenvalues & Eigenvectors
6.1 Definition · 6.2 Finding eigenvalues · 6.3 Finding eigenvectors · 6.4 Diagonalisation · 6.5 Matrix powers

Core idea and definition

An eigenvector is a non-zero vector that doesn't rotate under A — only its length scales. The scale factor is the eigenvalue.

Av = λv (v ≠ 0) To find eigenvalues: solve det(A − λI) = 0 Check answers using: trace(A) = λ₁ + λ₂ + ··· + λₙ det(A) = λ₁ · λ₂ ··· λₙ Triangular A → eigenvalues = diagonal entries

Finding eigenvectors

For each λ, solve (A−λI)v=0. The solution space is the eigenspace of λ.

Geometric multiplicity = dim(eigenspace) Algebraic multiplicity = power of (λ−λ₀) in char. poly Always: 1 ≤ geometric mult ≤ algebraic mult
Eigenvectors from different eigenvalues are always linearly independent. The zero vector is NEVER an eigenvector.

Diagonalisation A = PDP⁻¹

A is diagonalisable iff it has n linearly independent eigenvectors. Build P with eigenvectors as columns, D with corresponding eigenvalues on diagonal.

Guaranteed diagonalisable: n distinct eigenvalues. May not be: repeated eigenvalues where geom. mult. < alg. mult.

Order matters: eigenvalue D[i,i] must correspond to eigenvector P[:,i]. Mismatching them gives A≠PDP⁻¹.

Matrix powers

If A = PDP⁻¹, then Aᵏ = PDᵏP⁻¹ Dᵏ = diag(λ₁ᵏ, λ₂ᵏ, ..., λₙᵏ) ← trivial Long-run: |λ|>1 grows, |λ|<1 decays to 0, |λ|=1 stays
Example. M has eigenvectors v₁=(−1,0,1), v₂=(−3,−2,1), v₃=(−5,4,1) with eigenvalues 4,2,0. Compute M⁵(3v₂+v₃).
1Key insight: M acts on eigenvectors by scalar multiplication. Mᵏvᵢ=λᵢᵏvᵢ.
2M⁵(3v₂+v₃)=3M⁵v₂+M⁵v₃=3·2⁵·v₂+0⁵·v₃=96·(−3,−2,1)+0=(−288,−192,96).
Warm-Up
Show A=[[1,2],[0,1]] is NOT diagonalisable over ℝ.
Characteristic equation: (1−λ)²=0 → λ=1 with alg. mult.=2. Eigenspace: (A−I)v=[[0,2],[0,0]]v=0 → one free variable → geom. mult.=1. Since 1 < 2, not diagonalisable. ∎

Topic 7 — Inner Product Spaces
7.1 Definition · 7.2 Geometry · 7.3 Gram-Schmidt · 7.4 Least Squares · 7.5 Orthogonal matrices · 7.6 Hermitian

4 axioms for an inner product

1. ⟨u,v⟩ = ⟨v,u⟩ (symmetry) 2. ⟨αu,v⟩ = α⟨u,v⟩ (scalar linearity) 3. ⟨u+v,w⟩ = ⟨u,w⟩+⟨v,w⟩ (additivity) 4a. ⟨u,u⟩ ≥ 0 (positivity) 4b. ⟨u,u⟩=0 ⟺ u=0 (definiteness)

Geometry from ⟨·,·⟩

‖v‖ = √⟨v,v⟩ cos θ = ⟨u,v⟩/(‖u‖‖v‖) proj_W v = Σᵢ ⟨v,uᵢ⟩uᵢ (uᵢ orthonormal basis for W)
To disprove ⟨·,·⟩ is an inner product: try u=(0,1) and check if ⟨u,u⟩ < 0. Axiom 4a is the most common failure.

Gram-Schmidt procedure

Given basis {v₁,...,vₖ} → orthonormal basis {u₁,...,uₖ}: Step 1: u₁ = v₁/‖v₁‖ Step 2a: w₂ = v₂ − ⟨v₂,u₁⟩u₁ Step 2b: u₂ = w₂/‖w₂‖ Step 3a: w₃ = v₃ − ⟨v₃,u₁⟩u₁ − ⟨v₃,u₂⟩u₂ Step 3b: u₃ = w₃/‖w₃‖ ... and so on
At each step, subtract projections onto ALL previous uᵢ before normalising. Missing one ruins everything.

Least squares — normal equations

Line y=a+bx for data points (x₁,y₁),...,(xₙ,yₙ): A=[[1,x₁],[1,x₂],...], y=(y₁,...,yₙ)ᵀ, u=(a,b)ᵀ Solve: AᵀAu = Aᵀy Formula: u = (AᵀA)⁻¹Aᵀy (if AᵀA invertible)

Orthogonal matrix

Q orthogonal ⟺ QᵀQ=I ⟺ Q⁻¹=Qᵀ det(Q) = ±1. Q preserves lengths and angles.

Spectral Theorem

Every real symmetric matrix (Aᵀ=A) is orthogonally diagonalisable: A=QDQᵀ where Q is orthogonal. All eigenvalues are real. Eigenvectors from different eigenspaces are orthogonal.

Hermitian (complex)

Hermitian inner product: ⟨u,v⟩=⟨v,u⟩* (conjugate symmetry) Standard on ℂⁿ: ⟨u,v⟩ = Σ uᵢv̄ᵢ ← conjugate the 2nd Unitary U: U*U=I (complex analogue of orthogonal) Hermitian H: H*=H (complex analogue of symmetric)
Example. Apply Gram-Schmidt to {(1,1,1),(0,1,1),(0,0,1)} with dot product.
1u₁=(1,1,1)/√3 = (1/√3, 1/√3, 1/√3).
2⟨v₂,u₁⟩=2/√3. w₂=(0,1,1)−(2/3)(1,1,1)=(−2/3,1/3,1/3). ‖w₂‖=√6/3. u₂=(−2/√6,1/√6,1/√6).
3w₃=(0,0,1)−(1/√3)u₁−(1/√6)u₂=(0,−1/2,1/2). ‖w₃‖=1/√2. u₃=(0,−1/√2,1/√2).

🧠 Exam Thinking Guide
See a question → know instantly which direction to think. This is what separates full marks from partial marks.
The exam is harder than tutorials. Questions rarely say "use Gram-Schmidt" or "find eigenvalues." They give you a situation and you must recognise which tool applies. This guide trains that instinct.
Topic 1 — Linear Equations

If the question involves…

system of equations→ Write [A|b], row reduce, classify by last row
parameter k in matrix→ Row reduce symbolically; [0…0|c]: inconsistent; [0…0|0]: free variable
fit polynomial to data→ Sub each data point → linear system in coefficients → solve
traffic flow / network→ Flow in = flow out at each node → linear system

Full marks checklist

row ops→ Label every step: R2→R2−2R1. Missing notation = lost marks.
parametric form→ Write x = x_p + t·v₁ + s·v₂ (particular + homogeneous)
no/unique/infinite→ Identify the decisive row; state condition explicitly
Topic 2 — Matrices & Determinants

If the question involves…

find A⁻¹→ Row reduce [A|I] → [I|A⁻¹]
prove something about AB→ Try multiplying both sides by A⁻¹ or B⁻¹
det with parameters→ Expand along row/column with most zeros
A²=A (idempotent)→ Take det both sides: det(A)²=det(A) → det∈{0,1}
is A invertible?→ Check det(A)≠0 or rank=n

Full marks checklist

(AB)⁻¹→ MUST reverse order: B⁻¹A⁻¹ not A⁻¹B⁻¹
det(kA)→ kⁿ·det(A) for n×n. Easy to forget the n.
proof by contradiction→ Assume det≠0, or A invertible, then derive.
Topic 3 — Euclidean Vectors

If the question involves…

plane through 3 points→ Two vectors in plane → cross product = normal → point-normal form
distance point to plane→ |ax+by+cz−d|/√(a²+b²+c²)
area of parallelogram→ ‖u×v‖. For triangle: half.
parallel / perpendicular?→ Parallel = direction vectors are scalar multiples. Perp = dot product=0.

Full marks checklist

line through 2 points→ direction = P₂−P₁. Line: x=P₁+t(P₂−P₁).
do lines intersect?→ Set parametric eqs equal, solve system; check consistency.
Topic 4 — Vector Spaces

If the question involves…

is W a subspace?→ Test 0∈W first. Then au+bv∈W for arbitrary a,b.
is v in span{...}?→ Row reduce [v₁|…|vₖ|v], check consistency.
linearly independent?→ Row reduce matrix (cols = vectors). Indep ↔ pivot in every col.
find null/col/row space→ All from ONE row reduction. Do it once, extract all three.
rank + nullity→ Must quote: rank+nullity=n (#columns). State this theorem.

Full marks checklist

column space basis→ Pivot cols of ORIGINAL matrix. NOT the RREF columns!
is it a basis?→ Check: (1) right number, (2) linearly independent. Both needed.
RREF changes→ RREF is unique. Any row op gives same RREF. Use this!
Topic 5 — Linear Transformations

If the question involves…

is T linear?→ Check T(0)=0 first. Then T(cu+dv)=cT(u)+dT(v).
find standard matrix→ Apply T to e₁,e₂,…,eₙ. Columns = T(eᵢ).
find kernel / image→ ker = null space of [T]. im = col space of [T].
injective? surjective?→ Injective ↔ ker={0}. Surjective ↔ rank=dim(codomain).
geometric transform→ Apply to basis vectors, read off columns. Use known matrix forms.

Full marks checklist

change of basis→ [T]_new = P⁻¹[T]P. State formula explicitly.
proving linearity→ Use ARBITRARY u,v,c,d. Never use specific examples as a proof.
Topic 6 — Eigenvalues

If the question involves…

find eigenvalues→ det(A−λI)=0. Always verify using trace and det.
eigenvectors given, find λ→ Compute Avᵢ directly and read off the scale factor.
Aᵏv for eigenvector v→ Aᵏv=λᵏv immediately. No matrix multiplication needed!
diagonalisable?→ Check geom.mult. = alg.mult. for ALL eigenvalues.
Aᵏ for large k→ Diagonalise A=PDP⁻¹, then Aᵏ=PDᵏP⁻¹.
Markov / long-run→ Find eigenvector for λ=1, normalise so entries sum to 1.

Full marks checklist

repeated eigenvalue→ Always check geom.mult. Not diagonalisable if geom < alg.
similar matrices A=PBP⁻¹→ Same eigenvalues, same char. poly, same trace and det.
triangular matrix→ Eigenvalues = diagonal entries. Always state this theorem.
Topic 7 — Inner Products

If the question involves…

is ⟨·,·⟩ an inner product?→ Test axiom 4a first: try u=(0,1). If ⟨u,u⟩<0 → done.
show uᵀAv is inner product→ A symmetric → axioms 1-3. Show A positive definite for axiom 4.
orthonormal basis needed→ Gram-Schmidt. Show every projection step explicitly.
project v onto W→ If {u₁,...} orthonormal: proj=Σ⟨v,uᵢ⟩uᵢ.
least squares line→ Build A (1s + x-values), solve AᵀAu=Aᵀy.
Hermitian/complex inner prod.→ Conjugate the SECOND argument. ⟨u,v⟩=Σuᵢv̄ᵢ.

Full marks checklist

Frobenius inner product→ ⟨A,B⟩=Tr(AᵀB). ‖A‖²=sum of squares of all entries.
orthogonal matrix proof→ From QᵀQ=I, take det: det(Q)²=1 → det(Q)=±1.
symmetric eigenvalues→ Always real. Different eigenspaces are orthogonal (state theorem).
🔴 Cross-Topic Patterns — Exam Favourites

Multi-part question structures

eigenvalue + Aᵏ→ Part 1: find λ. Part 2: diagonalise. Part 3: compute Aᵏ or limit.
inner product + projection→ Part 1: verify inner product. Part 2: check orthonormal. Part 3: project.
RREF given → deductions→ Extract row space, col space, null space, rank, nullity all at once.
show T linear + find matrix→ Part 1: prove linearity with arbitrary vectors. Part 2: apply to basis vectors.

Proof patterns

prove B=0 given AB=0→ A invertible: left-multiply by A⁻¹.
eigenvalue of A⁻¹→ Start Av=λv, multiply by A⁻¹, get A⁻¹v=(1/λ)v.
det(Q)=±1 for orthogonal→ Start QᵀQ=I, take det both sides.
not a subspace→ Try zero vector first. Then try sum of two elements.
similar matrices same λ→ A=PBP⁻¹, Av=λv → Bw=λw where w=P⁻¹v.
